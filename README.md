## ✨ Features

- **🤖 AI Multi-Modal Audit Engine:** Leverages Google Gemini 2.0 Flash API to audit checkout URLs, promo texts, and screenshot images for deceptive UI/UX practices.
- **📸 Vision Screenshot Inspection:** Detects low-contrast disclaimers, pre-checked checkboxes, and sneaky subscription auto-renewals directly from image uploads.
- **📊 Real-Time Deception Scoring:** Calculates a risk percentage score (0–100%) and classifies merchant risk into **Safe / Low Risk**, **Medium Risk**, or **Critical Threat**.
- **🌐 Community Threat Index:** A crowd-sourced voting and reporting system where users log confirmed traps and rate merchant transparency.
- **📜 Local Audit Dashboard:** Tracks scan history, records saved traps avoided, and manages user reputation scores locally.
